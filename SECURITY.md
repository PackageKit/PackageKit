# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| 1.3.x   | :x:                |

## Reporting a Vulnerability

We have enabled private reporting in GitHub, so please [follow these steps](https://github.com/PackageKit/PackageKit/security)
to report vulnerabilities.

If you report a vulnerability in a specific backend, please also reach out to the affected distribution, as they might be able
to help out to resolve the issue sooner and will be affected by the issue.
